# Моя шпаргалка по Git

Основные команды, которые я использую, чтобы не забывать.

## 📥 Настройка и клонирование

| Команда | Что делает |
| :--- | :--- |
| `git config --global user.name "Твоё Имя"` | Устанавливает имя для всех коммитов. |
| `git config --global user.email "твоя@почта.com"` | Устанавливает email для всех коммитов. |
| `git clone <url>` | Скачивает удалённый репозиторий к себе на компьютер. |
| `git clone --depth 1 <url>` | Скачивает только последнюю версию (быстрее для больших проектов). |

## 📍 Основные команды для локальной работы

| Команда | Что делает |
| :--- | :--- |
| `git init` | Создаёт новый Git-репозиторий в текущей папке. |
| `git status` | Показывает, какие файлы изменены или готовы к сохранению. |
| `git add <файл>` | Добавляет файл в список «на сохранение» (staging area). |
| `git add .` | Добавляет **все** изменённые файлы в список. |
| `git commit -m "текст"` | Сохраняет (коммитит) добавленные изменения с понятным описанием. |

## 🌐 Работа с удалённым репозиторием (GitHub)

| Команда | Что делает |
| :--- | :--- |
| `git remote -v` | Показывает адрес удалённого репозитория. |
| `git push` | Отправляет мои коммиты на GitHub. |
| `git pull` | Скачивает чужие изменения с GitHub ко мне. |

## 🧠 Всё о логах и HEAD

### Команда `git log`

| Команда | Что делает |
| :--- | :--- |
| `git log` | Показывает полную историю коммитов (автор, дата, сообщение). |
| `git log --oneline` | Показывает историю сокращённо: **хеш** и **сообщение** коммита. |
| `git log --graph` | Показывает историю с визуальными ветками (полезно при merge). |
| `git log --oneline --graph` | Комбо: сокращённые коммиты + ветки. |
| `git log -n 3` | Показывает только последние 3 коммита. |

### Указатель `HEAD`

`HEAD` — это указатель на **текущий коммит**, в котором ты сейчас находишься.

| Команда / Концепция | Что делает |
| :--- | :--- |
| `HEAD` | Указывает на последний коммит текущей ветки. |
| `HEAD~1` | На один коммит назад от `HEAD`. |
| `HEAD~3` | На три коммита назад. |
| `git show HEAD` | Показывает содержимое текущего коммита. |
| `git show HEAD~1` | Показывает содержимое предыдущего коммита. |
| `git reset HEAD~1` | Перемещает `HEAD` на один коммит назад (изменения сохраняются). |
| `git reset --hard HEAD~1` | Перемещает `HEAD` на один коммит назад **и удаляет изменения**. |

## 🧹 Если что-то пошло не так

| Команда | Что делает |
| :--- | :--- |
| `git reset HEAD~1` | Отменяет последний коммит, но сохраняет изменения в файлах. |
| `git reset --hard HEAD~1` | Отменяет последний коммит **и** удаляет все изменения. |
| `git checkout -- <файл>` | Откатывает файл до последнего сохранённого состояния. |

## 💡 Полезные советы

*   Делай маленькие коммиты с понятными сообщениями.
*   Всегда делай `git pull` перед тем, как начать новую работу.
*   Не бойся экспериментировать, Git всё помнит.
*   `git log --oneline --graph` — твой лучший друг при разборе истории и веток.
